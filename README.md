# hanBoost

**hanBoost** waa app-kaaga cusub oo ka tirsan **Hanadora**, oo lagu dhisay AI Studio. Version-kan wuxuu ku socdaa magaca **hanZOZ**.

Halkan waxaad ka helaysaa wax kasta oo aad u baahan tahay si aad app-ka loogu wado local-ka (computer-kaaga).

Fiiri app-kaaga AI Studio: https://ai.studio/apps/15d136bf-2816-4b41-87dc-4f5dd269c6cf

## U Wadista Local-ka (Run Locally)

**Waxyaabaha loo baahan yahay:**
[Android Studio](https://developer.android.com/studio)

**Tillaabooyinka:**

1. Fur Android Studio
2. Dooro **Open**, kadibna dooro folder-ka ay ku jirto project-kan
3. U ogolow Android Studio inuu isaga hagaajiyo wax kasta oo aan is waafaqsanayn markuu soo dejinayo project-ka
4. Samee file cusub oo magaceedu yahay `.env` gudaha project-ka, kadibna geli `GEMINI_API_KEY` (fiiri `.env.example` tusaale ahaan)
5. Ka saar line-kan file-ka `build.gradle.kts`:
   `signingConfig = signingConfigs.getByName("debugConfig")`
6. App-ka ku wad emulator ama device dhab ah
